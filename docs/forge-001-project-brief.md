# FORGE 001 — AI Control Baseline Project Brief

## Project Name

FORGE 001 — AI Control Baseline

## Project Purpose

FORGE 001 is the first formal project in the FORGE AI Control Engineering portfolio.

The purpose of this project is to demonstrate a practical method for assessing an enterprise AI system before it becomes operationally dangerous, over-permissioned, poorly governed, or impossible to audit.

This project uses the synthetic Front Range Mechanical scenario to model a realistic business environment where an AI assistant is introduced into service operations.

## What This Project Proves

This project is designed to prove the ability to:

- Identify AI system purpose, ownership, users, data sources, and permitted functions.
- Separate AI recommendation, preparation, and action authority.
- Map sensitive data exposure and operational risk.
- Define governance, security, identity, authorization, evidence, and review controls.
- Produce auditor-readable documentation.
- Translate ambiguous AI use cases into structured controls.
- Build reusable AI governance and control artifacts.

## Target Audience

This project is intended to be understandable and useful to:

- Security governance teams
- Data governance teams
- AI governance teams
- Compliance and audit stakeholders
- Microsoft 365 / Purview administrators
- Small and mid-sized business leaders
- Upwork prospects seeking AI governance help
- Recruiters or hiring managers evaluating practical AI control capability

## Synthetic Client

Front Range Mechanical is a synthetic mechanical services company piloting an AI-assisted service operations tool.

The company uses Microsoft 365, SharePoint, Teams, customer service documentation, field technician notes, and internal procedures.

## Core Problem

The business wants the productivity benefits of AI, but it needs to know:

- What the AI system can access
- What the AI system can do
- Who owns the system
- What data is exposed
- What actions require approval
- What evidence must be retained
- What risks exist
- What controls should be implemented before expansion

## Core Deliverables

FORGE 001 will produce the following deliverables:

1. AI System Inventory
2. AI Risk Register
3. AI Control Matrix
4. AI Evidence Map
5. Executive Baseline Report

## Control Domains

The project will examine the AI system through the following control domains:

- Ownership and accountability
- Data access
- Identity and permissions
- Human approval
- Action boundaries
- Sensitive information exposure
- Evidence and logging
- Change management
- Review cadence
- Exception handling

## Success Criteria

FORGE 001 is successful when it produces a complete, reusable AI Control Baseline package that can be shown publicly as evidence of AI Control Engineering capability.

The final package should be strong enough to support:

- A GitHub portfolio repository
- A LinkedIn article or post series
- An Upwork service offering
- A sample client deliverable
- A discussion with a hiring manager or recruiter
- A foundation for later FORGE projects

The central operating principle of FORGE 001 is:

Useful AI is not automatically safe AI. Enterprise AI must be inventoried, bounded, controlled, evidenced, and reviewed.
